# 小学作业生成器（zuoye-fluter）

中国小学作业生成工具（Flutter 版）：一键生成可打印的小学 **练字帖 / 语文 / 数学 / 英语** 作业，
支持 **AI 出题** 与 **AI 帮答题**，可导出 A4 PDF 或直接打印。

目标平台 **Windows 桌面版 + Android APK + Web**。

## 功能

- ✍️ **练字帖**：田字格描红，按所选教材各年级上下册生字生成，可自定义文字；练习次数 / 每行字数 / 每页行数可调
- 📖 **语文作业**：看拼音写汉字、汉字注拼音（四线三格）、生字组词、古诗名句 / 成语 / 名言填空、课文阅读（可导入语料）、阅读理解（AI 生成）
- 🔢 **数学作业**：各年级上下册题型（口算 / 竖式 / 长除法 / 应用题 / 单位换算 / 比较大小等），计算题答案精确无浮点误差
- 🇬🇧 **英语作业**：字母书写、单词抄写、中英连线、中译英 / 英译中、单词拼写、听力练习、阅读理解（AI 生成）
- 🤖 **AI 出题**：多科多题型混合作卷，每个题型可单独设题量，题型按「教材版本 × 年级」自动过滤
- 💡 **AI 帮答题**：拍照或输入题目，AI 分步骤讲解并给出答案
- 📥 生成 A4 作业，一键导出 PDF（系统另存为对话框）或打印

## 教材依据

人教版（部编版语文 / 人教版数学 / 人教 PEP 英语）、冀教版（数学 + 英语）、
外研版（英语·一年级起点 / 三年级起点）、统编版，均按上、下册分离。

各版本提供的科目并不相同（如外研版只有英语、且三起点没有一二年级），
应用会按版本自动裁剪科目与年级，并在切换时归一化越界的年级。

## 使用说明

- **AI 功能需自备大模型 API Key**：支持 OpenAI 兼容接口（DeepSeek、通义、Kimi、智谱、小米 MiMo、本地 Ollama 等），
  在应用内「AI 智能出题设置」填入 API 地址、模型与 Key 即可
- Key 以系统级加密保存（Windows DPAPI / 安卓系统密钥库 Keystore），仅存本机、不联网上传
- **记忆你的设置**：教材版本 / 学期 / 年级、各题型题量、面板显示选项、AI 科目与对话都会自动保存，重开仍在

## 设计要点

试卷的**版式**与**内容正确性**是本项目的两条主线，代码里有多处约定值得留意：

- **预览即试卷**：PDF 是对预览 Widget 截图后嵌入 A4 的，所以「所见即所得」天然成立，不需要维护两套渲染
- **题型可用性只有一个来源**：`lib/core/type_catalog.dart`（`TypeCatalog`）。
  数学取教材数据里的题型列表、语文按年级区间、英语按区间叠加版本规则，三科都由它统一裁决
- **超纲校验**：本地生成有硬约束（题型 + 数值上限 + 按年级分桶的语料）；
  AI 生成是软约束，因此加了生成后校验 `ScopeGuard`（数学查 1–3 年级数值、语文查三种字词题型的生字越界率）
- **排版遵循真实试卷**：大题中文序号跨页连续、得分栏含「总分」列、小题序号与题目同行、
  同一大题被拆页时续页标「（续）」且不重复编号
- **长除号「厂」形是手绘的**：不用 Unicode 的 `⟌`(U+27CC)——该字符字形随字体而异，
  会让同一个应用在 Android 与浏览器上显示成两个样子

更细的约定与踩坑记录见 **[AGENTS.md](AGENTS.md)**，
数据结构、维度关系与持久化设计见 **[docs/DATA_MODEL.md](docs/DATA_MODEL.md)**。

## 开发

```bash
# 安装依赖
flutter pub get

# 校验（analyze + 测试 + 版本一致性）
bash scripts/validate.sh

# 构建
flutter build apk --release      # Android（需 JDK 21）
flutter build web --release      # Web
flutter build windows --release  # Windows（需 Windows 环境）
```

测试共 200+ 条，覆盖数据加载、三科分页、题型目录、超纲校验、持久化、
多屏宽布局冒烟等；其中相当一部分是**反漂移守卫**（防止同一规则被实现两遍后走偏）。

### 版本号（唯一来源 `pubspec.yaml`）

只改 `pubspec.yaml` 的 `version`（如 `3.1.0+30100`，`+` 后为 versionCode），
然后运行 `node scripts/sync-version.js` 同步 `lib/data/app_data.dart`。

> CI 的构建任务是**按版本号变化触发**的：只推代码不改版本号，
> 只会跑 analyze + test，不会编译产物、也不会发 Release。

### 数据

`assets/data.json` 由原 JS 项目的 `js/data.js` + `js/yuwen-corpus.js` 转换生成，**勿手改**。
完整结构说明见 [docs/DATA_MODEL.md](docs/DATA_MODEL.md)。

### Android 签名

Release 构建使用固定签名密钥（本地 `android/key.properties`；CI 从 GitHub Secrets 还原），
保证版本间签名一致可覆盖安装。密钥文件不入库。
